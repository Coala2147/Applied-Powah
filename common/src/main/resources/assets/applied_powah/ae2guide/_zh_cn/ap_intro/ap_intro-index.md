# 附加模组：Applied Powah

**Applied Powah** 是 [Applied Energistics 2](../ae2-mechanics/ae2-mechanics-index.md) 的附属模组
（Minecraft 1.20.1 Forge）。它提供大容量 AE 能源元件、可从 ME 网络取能并供给附近
**Powah** 充能台的全方块**充能棒**，以及三个接入 ME 网络的充能台——其中 ME 充能台可以直接
接收来自 ME 网络的合成任务。

**本模组改变玩法并新增物品——服务端与客户端都需要安装。**

## 依赖

| 模组 | 要求 |
|-----|-------------|
| Minecraft 1.20.1 + Forge 47+ | 必需 |
| Applied Energistics 2 15+ | 必需 |
| GuideME | 必需（AE2 依赖，即本书） |
| Powah 5+ | 推荐（充能台配方与供能目标） |
| Applied Flux 1+ | 可选（ME 棒抽 FE） |
| JEI 15+ | 可选（在 Powah 充能类别中显示棒/台催化剂） |
| Jade / WTHIT / TOP | 可选（覆盖层提示；能量显示走 AE2 的集成） |

悬停 Applied Powah 物品时按 **G** 可打开对应说明。
