# Applied Powah

**Applied Energistics 2** 附属模组：更大容量的 AE 能源元件，以及从 ME 网络取能、供给附近 **Powah** 充能台的充能棒。

**需要：** Minecraft 1.20.1 + Forge、Applied Energistics 2。  
**可选：** Powah（棒供给其充能台）、Applied Flux（ME 棒抽 FE）。

悬停 Applied Powah 物品时按 **G** 可打开对应说明。
