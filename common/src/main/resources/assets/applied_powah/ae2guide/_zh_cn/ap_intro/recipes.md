# 配方

- **AE 棒：** 四边 AE2 能源元件摆成十字 + 中心同档 Powah 充能棒。
- **ME 棒：** 四角 AE2 能源元件 + 中心同档 Powah 充能棒。
- **升级：** 与 Powah 棒升级相同，中心换成上一档 AP 棒。
- **AE ↔ ME：** 同档无序互转。
- **能源元件：** 8× 上一级元件 + 1 个运算处理器。

未安装 Powah 或 Applied Flux 时，相关配方会自动消失。
