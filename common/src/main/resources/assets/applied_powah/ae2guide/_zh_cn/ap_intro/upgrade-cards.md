# 升级卡

充能台升级槽（GUI 里那一排小槽）专用卡。三个系列，各有槽位预算：

| 系列 | 最多同时安装 | 效果 |
|--------|---------------|--------|
| <ItemLink id="applied_powah:thread_card_p1" /> … <ItemLink id="applied_powah:thread_card_p8" /> | **1** | 额外并发线道：充能台同时进行更多批配方（+1 / +2 / +4 / +8） |
| <ItemLink id="applied_powah:parallel_card_x2" /> … <ItemLink id="applied_powah:parallel_card_x8" /> | **1** | 批量倍率：每轮产出配方结果的 ×2 / ×4 / ×6 / ×8 |
| <ItemLink id="ae2:energy_card" /> | **4** | 更大能量缓存与更快的网络 IO（AE2 原版卡，无需 AP 版本） |

充能台共有 **6** 个升级槽；各系列上限在插入时强制执行。

更高档位把上一档卡放在中间，四周放 AE2 空间元件与处理器，顶档需要**奇异物质**。
