# Add-on: Applied Powah

**Applied Powah** is an [Applied Energistics 2](../ae2-mechanics/ae2-mechanics-index.md) addon for
Minecraft 1.20.1 Forge. It adds high-density AE energy cells and full-block
**Energizing Rods** that draw energy from an ME network and supply nearby
**Powah** Energizing Orbs — plus three grid-aware orbs of our own, one of which
takes crafting jobs straight from the network.

**This mod changes gameplay and adds items — install on both server and client.**

## Dependencies

| Mod | Requirement |
|-----|-------------|
| Minecraft 1.20.1 + Forge 47+ | Required |
| Applied Energistics 2 15+ | Required |
| GuideME | Required (AE2 dependency — this book) |
| Powah 5+ | Recommended (orb recipes and feed targets) |
| Applied Flux 1+ | Optional (ME rod FE extraction) |
| JEI 15+ | Optional (rod/orb catalysts on the Powah Energizing category) |
| Jade / WTHIT / TOP | Optional (overlay tooltips; energy via AE2's integration) |

Hold **G** on an Applied Powah item to open its page.
