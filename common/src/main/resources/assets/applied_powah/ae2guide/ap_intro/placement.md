# Placement

## Energizing rods

1. Must be placed adjacent to an AE2 cable (glass / covered / smart, including colours).
2. Targeting a cable while placing sets `facing` toward that cable.
3. Single adjacent cable → face that cable.
4. Multiple cables, none targeted → south, then east, then any adjacent cable.
5. No cable → cannot place. If the cable is removed later, the rod may drop.

## Energy cells

Place like AE2 energy cells; rod cable-host rules do not apply.
