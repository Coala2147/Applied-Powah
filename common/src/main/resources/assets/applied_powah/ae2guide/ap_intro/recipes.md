# Recipes

- **AE rod:** AE2 energy cells in a **cross** + same-tier Powah rod in the center.
- **ME rod:** AE2 energy cells in the **corners** + same-tier Powah rod in the center.
- **Upgrade:** same pattern as Powah rod upgrades — put the previous AP rod in the middle.
- **AE ↔ ME:** shapeless swap for the same tier.
- **Energy cells:** 8× the previous cell + 1 calculation processor.

Some recipes disappear if Powah or Applied Flux is not installed.
