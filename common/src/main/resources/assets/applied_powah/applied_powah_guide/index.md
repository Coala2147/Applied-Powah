# Applied Powah

Applied Powah is an addon for **Applied Energistics 2** on Minecraft 1.20.1 Forge.
It adds high-density AE energy cells and full-block energizing rods that draw energy
from an ME network and supply nearby Powah Energizing Orbs.

## Dependencies

| Mod | Requirement |
|-----|-------------|
| Minecraft 1.20.1 + Forge 47+ | Required |
| Applied Energistics 2 15+ | Required |
| GuideME | Required in practice (AE2 hard dependency); this book uses it |
| Powah 5+ | Recommended (Energizing Orb and rod upgrade materials) |
| Applied Flux 1+ | Required for ME rods to extract FE from the ME network |

## Tooltips

Item tooltips use the AE2 energy sentence form and light-gray text.
Rod and cell **items** do not display live stored energy (energy lives in the placed block entity).
Hold **G** on an item that lists this book in `item_ids` to open the matching page.
