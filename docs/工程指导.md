## 0. 一句话

在 **Minecraft 1.20.1 Forge** 上做 **Applied Powah**：把 **AE2 × Powah** 缝在一起——高密度 AE 能源元件 + 从 AE/ME 网络取能、喂 Powah 充能台的 **AE/ME Energizing Rod（AE2 part）**。

## 2. 功能范围

### 2.1 本期要做

1. **超密 / 极密能源元件**（AE2 方块，挂 ME 网络）。  
2. **AE Energizing Rod / ME Energizing Rod**（7 档，AE2 **part**）。  
3. 配方：原版→AP 转入、AP 逐级升级、AE↔ME、门控。  
4. 取能：AE 棒抽 AE；ME 棒抽 Applied Flux 的 ME FE；喂附近 Powah 充能台。  
5. 配置：缓存/输出对齐 Powah；输入量与间隔可调。  
6. 挖掘：扳手潜行快拆；掉落 **清空 FE** 的 part 物品。  
7. **Jade 兼容**。

### 2.2 展望（本期不实现）

- **无线充能棒**（不是「便携」；类似 EAE 无线连接器思路，另期）。  
- Powah「能量单元」→ AP 新组件 + **kubejs**（超密/极密仍保留）。  
- NeoForge 正式支持；Applied Generators 深度交互。

## 5. AE / ME Energizing Rod

### 5.1 形态与网络【已拍板】

- **AE2 part**，挂 cable bus（与终端/总线同类交互）。  
- 全称：`AE Energizing Rod` / `ME Energizing Rod` + 档位（如 Basic）。  
- **AE 棒**：从 **AE 网格**取 AE。  
- **ME 棒**：从 **ME 网络 FE**（Applied Flux `FluxKey`/`IStorageService`）取 FE，**不是** AE 折 FE。  
- 放电：附近有 Powah 充能台时，按 Powah 棒逻辑 `orb.fillEnergy` 推入。  
- 无频道/节点不活跃：**不取能**（对齐 AE2 `ChannelPowerSrc`）。  
- 有频道：节点 **idle = 1.0 AE/t**【已拍板：先用通用值】；网络频道税由 AE2 自动处理（`channelsByBlocks/128`）。

### 5.2 能量参数【已拍板】

**内部缓存 = 暂用 Powah `energizing_rods` config（Forge 默认）**

| 档位 | Tier | 缓存 FE | 输出 transfer FE/t（喂台） |
|------|------|---------|---------------------------|
| 初级 | starter | 10_000 | 100 |
| 基础 | basic | 40_000 | 400 |
| 硬化 | hardened | 100_000 | 1_000 |
| 烈焰 | blazing | 400_000 | 4_000 |
| 钻石 | niotic | 1_000_000 | 10_000 |
| 富生 | spirited | 4_000_000 | 40_000 |
| 下界 | nitro | 20_000_000 | 200_000 |

**取能（入能）**

| 项 | 规则 |
|----|------|
| 节奏 | 间隔抽取（「爆发式」设计语义）；**暂定每 1 tick**，**config 可调** |
| **每次抽取量** | 全档统一 = **最高级缓存** |
| **ME 棒** | 量以 **FE** 计：**20_000_000 FE** |
| **AE 棒** | 量以 **AE** 计：**10_000_000 AE**（对应 20M FE，按 **÷2**；对齐 AE2 `PowerRatios.ForgeEnergy=0.5` 语义） |
| 输出 | 用上表 **Powah transfer**，不随「统一输入」改变 |

### 5.3 网络取能保护（安全封顶）【已拍板】

| 项 | 规则 |
|----|------|
| 抽取量上限 | **默认无上限**（可按 §5.2 的「每次抽取量」尽量抽） |
| **网络保留** | 从 **AE 网络**抽取后，**须为网络保留其能量上限的 5%**（即最多抽到网格还剩 `max×5%` 为止） |
| 可配置 | 该比例 **config 可调**（字段名实现时定，如 `network_reserve_ratio`，默认 **0.05**） |
| ME/FE | 保护规则以 **AE 网格** 表述为准；ME 侧抽取是否另设保留 **未单独拍板** → 实现时对 AE 网格强制 5% 保留；FE 抽取是否镜像该规则 **待你有意见时再改**，默认不对 FE 库存另设 5%（因 FE 存在 Flux 元件而非网格缓冲） |

### 5.4 挖掘【已拍板】

- 扳手潜行右键：快速拆除。  
- 空手/传统工具：与原版 AE2 方块一致（无明显加速）。  
- **掉落对应档 part 物品；内部 FE 清空（不保留）。**

## 6. 配方总表【已拍板】

约定：`a` = **能源元件**（AE2 Energy Cell）；`b` = **同档 Powah 充能棒**；升级时材料结构仿 Powah。

### 6.1 原版棒 → AP 棒（全部 7 档，均由 Powah 棒转入）【已拍板】

**无论 AE 还是 ME、无论哪一档，AP 棒都由对应 Powah 棒合成而来。**

**AE**（十字 + 中心同档 Powah 棒）：

```
_ a _
a b a
_ a _
→ AE Energizing Rod (该档)
```

**ME**（四角 + 中心同档 Powah 棒）：

```
a _ a
_ b _
a _ a
→ ME Energizing Rod (该档)
```

- `a` = AE2 **能源元件**；`b` = **同档** `powah:energizing_rod_<tier>`。  
- 档位：starter, basic, hardened, blazing, niotic, spirited, nitro —— **7 档各一对 AE/ME**。

### 6.2 AP 棒逐级升级【已拍板】

**就是 Powah 的合成配方，把其中的棒换成 AP ROD。**

- 逐档对照 `refs/1.20.1/Powah-1.20.1/.../data/powah/recipes/crafting/energizing_rod_*.json`。  
- **AE 升级**：配方里「上一档 Powah 棒」→ **上一档 AE 棒**，产物 = 下一档 AE 棒；石英/电容器/外壳等 **与 Powah 该档配方相同**。  
- **ME 升级**：同理，棒位换 **ME 棒**。  
- Powah 链（源码）：`starter → basic → hardened → blazing → niotic → spirited → nitro`（starter 无上一档棒，由 §6.1 从 `powah:energizing_rod_starter` 转入）。

### 6.3 AE ↔ ME 互转【已拍板】

1. **存储台**：丢存储台可互转（历史约定）。  
2. **无序合成 7 对**（本轮新增）：  
   - `AE Energizing Rod (X)` ⇄ `ME Energizing Rod (X)`  
   - X = starter, basic, hardened, blazing, niotic, spirited, nitro  
   - 每档双向各一条 shapeless（共 14 条 JSON，或实现时用对称配方生成）。

### 6.4 门控【已拍板】

| 环境 | 可合成 |
|------|--------|
| AE2 + Powah + Flux | 全部：元件 + AE 棒 + ME 棒 + 升级 + 互转 |
| AE2 + Powah（无 Flux） | 元件 + **AE 棒**及其升级；**无 ME 棒/ME 相关** |
| AE2 only（无 Powah） | **仅** 超密/极密元件 |
| 无 AE2 | 本 mod 依赖 AE2 API，设计上应 **不加载或空实现不崩**（与「软依赖」一致；实现细节【计划】） |

## 7. 网络风险

- 直接抽 AE 可能耗尽网格；FE 等吞吐也会耗 AE 网络能源。  
- **保护规则见 §5.3**：默认抽取量无上限，但 **AE 网络保留上限的 5%（config 可调）**。
