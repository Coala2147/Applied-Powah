## 2. 网络连接（已拍板）

| 项 | 规则 | 依据 |
|----|------|------|
| **默认** | 充能台 **仅底面** 接入 AE2 网络 | 你指定：类似 ExtendedAE ME Caner 的「限定面」思路；Caner 源码为 **TOP+BOTTOM**（`TileCaner.getGridConnectableSides`），AP 台更严：**仅 BOTTOM** |
| **可选** | `energizing_orb.orbMultiFacing=true` 时允许多面（测试用） | 与棒一致的多 facing 语义 |
| **默认值** | `orbMultiFacing = false` | 你指定：默认不开，测试环境开 |

实现要点（编码阶段）：

```java
// 默认
getGridConnectableSides → EnumSet.of(Direction.DOWN)
// config true
→ 与棒相同：facing 侧或六面策略（实现时二选一并写进 config 注释）
```

放置：底面下有 AE2 线缆才可放（或允许放置但仅底面可连网——**建议**：可放置，但无底缆则节点不活跃/无频道不取能，避免误拆）。

## 3. 两台设计摘要（计划 §3，编码时以 refs 为准）

### 3.1 ME 充能台 `me_energizing_orb`

| 项 | 设计 |
|----|------|
| 配方执行 | Powah `Recipes.ENERGIZING` / `EnergizingRecipe`，6 输入 + 1 输出 |
| 取能 | **默认不**从 AE 网抽能（计划默认）；仍可被原版/AP 棒 `fillEnergy` 喂 |
| ME 弹出 | 开关打开 → 输出槽 `IStorageService.insert`（抄 Interface 思路） |
| 网络面 | **仅底**（或 multiFacing） |
| 棒桥 | **必须**扩展 `PowahBridge`：目前只认 `owmii...EnergizingOrbTile`，AP 台要能被棒识别并 `fillEnergy` |

### 3.2 高级充能台 `advanced_energizing_orb`

| 项 | 设计（计划默认） |
|----|------------------|
| 形态 | **一种方块**；槽内棒类型决定抽 AE 还是 FE |
| 棒槽 | 4×最多 16 根 AP 棒；四槽同类（全 AE 或全 ME）；不要求同档 |
| 并行 | 最多 4 任务页，每页 6+1 |
| 缓存 | \(\sum n_i C(t_i)\)；输出 \(\sum n_i T(t_i)\)；输入 \(64 \times \max C(t_i)\) |
| 网络面 | 同上，**仅底** 默认 |
| UI | 占位 GUI + 翻页 + 进度条 + 弹出开关 |

**未决（开工前可改）**：合成配方是否仍用「7×nitro + ME 台 + 能源接收器」；你已表示配方需再论证，**0.2.1-alpha 不锁死配方 JSON**。

## 5. Powah 掉落（本版已实现，小修）
